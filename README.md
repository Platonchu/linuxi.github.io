# Linuxi Bank

Статический интерфейс для демонстрации управления тестовыми счетами. Данные загружаются из `data.json`; сайт публикуется как статическая страница.

## Запуск локально

Откройте папку проекта в терминале и запустите любой статический сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>. Для сохранения изменений нужен токен доступа с правом чтения и записи в хранилище проекта.

## Важно о безопасности

Это клиентское демо, не банковская система и не место для настоящих персональных или финансовых данных. PIN-код хранится в виде хеша, а не в открытом виде, но это всё ещё только клиентская защита и не подходит для реального продакшена. Для настоящего сервиса проверка доступа и хранение данных должны быть вынесены на сервер с авторизацией: секреты нельзя безопасно скрыть в статическом сайте.

Токен вводится в браузере и хранится в `localStorage`, поэтому его может прочитать любой скрипт, выполняющийся на странице. Не используйте токен с широкими правами или на недоверенном устройстве.

Приложение безопасно отображает текстовые данные, проверяет структуру записей и отключает операции, если файл не удалось корректно загрузить. Перед сохранением оно проверяет, не изменились ли данные с момента загрузки.
