# Linuxi Bank — игровая версия

Статический игровой проект с регистрацией, входом, игровым балансом, переводами �� историей операций. Пользователи хранятся в `users.json`, а игровые счета — в `data.json`.

## Как играть

Открой сайт, выбери «Регистрация», введи уникальный логин, пароль (не короче 6 символов) и токен с правами записи в файлы проекта. На счет начисляется стартовый бонус 100 ЛК. После регистрации в этом браузере можно входить по логину и паролю; токен сохраняется в cookie на 30 дней. Чтобы играть на другом устройстве, там тоже потребуется ввести токен для записи.

Запуск для локальной проверки:

```bash
python3 -m http.server 8000
```

Открой <http://localhost:8000>.

## Важно

Это только игровая авторизация, не настоящая система защиты. GitHub Pages публикует файлы как статические ресурсы: `users.json` и `data.json` доступны читателям репозитория и могут быть скопированы. Хеширование пароля в браузере не заменяет проверку на сервере. Токен cookie создаётся JavaScript-кодом и не имеет флага `HttpOnly`, поэтому скрипты страницы могут его прочитать. Не используй реальные пароли, настоящие персональные данные или токен с широкими правами; для настоящей приватности нужен сервер с авторизацией.
