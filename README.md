# Linuxi Bank

Статический интерфейс для демонстрации управления тестовыми счетами. Данные загружаются из `data.json`; приложение публикуется через GitHub Pages.

## Запуск локально

Откройте репозиторий в терминале и запустите любой статический сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>. Для сохранения изменений приложение обращается к GitHub Contents API; нужен токен с правом `Contents: Read and write` для этого репозитория.

## Важно о безопасности

Это клиентское демо, не банковская система и не место для настоящих персональных или финансовых данных. PIN-код находится в публичном HTML и не является защитой. GitHub token вводится в браузере и хранится в `localStorage`, поэтому его может прочитать любой скрипт, выполняющийся на этой странице, и он не должен быть широких прав или использоваться на недоверенном устройстве. Для настоящего сервиса запись следует переносить на сервер с авторизацией; секреты нельзя безопасно скрыть в статическом сайте.

Приложение отображает данные из `data.json` через безопасные DOM-текстовые узлы, проверяет структуру/ID/балансы и отключает операции, если файл не удалось корректно загрузить. Перед сохранением сравнивает загруженную версию с текущей, чтобы заметить параллельные изменения.
