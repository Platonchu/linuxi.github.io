# Linuxi Bank

Статическое приложение для игровых счетов, переводов, истории операций и каталога антикасаний. Сборка не требуется: GitHub Pages публикует файлы репозитория.

## Важно

Выбор профиля — это не вход и не проверка личности: у статического сайта нет серверной авторизации. Все посетители могут выбрать любой профиль. Изменения балансов, истории и покупок сохраняются только в `localStorage` текущего браузера, поэтому они не синхронизируются между устройствами или пользователями и могут быть изменены владельцем браузера. Не используйте сайт для реальных денег или личных данных.

Не помещайте пароли, API-ключи, GitHub token или другие секреты в HTML, JavaScript, JSON, GitHub Pages или `localStorage`. Для защищённого входа и общих данных нужен backend с серверной проверкой прав и базой данных.

## Функции

- выбор профиля и просмотр игрового счёта;
- пополнение, снятие и переводы между счетами;
- список операций;
- каталог и покупка антикасаний;
- локальное сохранение и сброс данных.

Суммы операций ограничены целыми числами от 1 до 1 000 000 ЛК. Счета находятся в `data.json`, каталог — в `anti-touch.json`, список профилей — в `users.json`. В `users.json` нет паролей; выбор профиля не является аутентификацией.

## Локальный запуск

В корне репозитория запустите статический сервер, например:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Не открывайте `index.html` напрямую через `file://`, так как браузер может блокировать загрузку JSON-файлов.

Если пароли публиковались ранее, считайте их скомпрометированными и смените везде, где использовались. Удаление файла новым коммитом не удаляет старые значения из Git-истории, форков и кешей.
