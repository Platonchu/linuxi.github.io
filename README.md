# Linuxi Bank — игровой демо-банк

Небольшое статическое приложение для демонстрации игровых счетов, переводов, операций и магазина антикасаний. Сайт публикуется через GitHub Pages и не требует сборки: откройте страницу сайта или запустите любой локальный HTTP-сервер в корне репозитория.

## Важно: только демо

GitHub Pages раздаёт HTML и JSON всем посетителям. Поэтому приложение не реализует настоящую авторизацию, не содержит секретов и ��е должно использоваться для хранения реальных денег или личных данных. Любой посетитель может выбрать любой демо-счёт. Изменения хранятся только в `localStorage` текущего браузера и не синхронизируются между пользователями или устройствами. Кнопка сброса возвращает данные к значениям из JSON-файлов.

Не добавляйте GitHub token, пароли, API-ключи или другие секреты в HTML, JavaScript, JSON, GitHub Pages либо `localStorage`. Для реальной авторизации и совместно используемых данных нужен доверенный backend с серверной проверкой прав и базой данных.

## Демо-возможности

- выбор тестового счёта;
- просмотр игрового баланса и истории операций;
- пополнение, снятие и переводы между демо-счетами;
- покупки из каталога антикасаний;
- локальное сохранение изменений и сброс демо-данных.

Суммы операций ограничены целыми числами от 1 до 1 000 000 ЛК. Данные счетов находятся в `data.json`, каталог — в `anti-touch.json`, список демонстрационных профилей — в `users.json`. В `users.json` нельзя хранить пароли: выбор профиля не является аутентификацией.

## Запуск локально

Откройте репозиторий в Codespaces либо запустите локальный статический сервер, например:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`. Не открывайте `index.html` напрямую через `file://`: браузер может блокировать загрузку JSON-файлов.

## Если пароли уже публиковались

Считайте их скомпрометированными: немедленно смените их везде, где они использовались. Удаление файла в новом коммите не стирает старые значения из Git-истории, форков или кешей. Если в репозитории были реальные учётные данные, отдельно оцените необходимость очистки истории и отзыва связанных токенов.
