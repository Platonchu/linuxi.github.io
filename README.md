# Linuxi Bank — игровой банк

Игровой сайт с аккаунтами, балансами, переводами и терминалом администратора.

## Вход администратора

- Логин: `Platonchu`
- Пароль: `Platon102938`

Администратор сразу получает доступ к терминалу без дополнительного PIN-кода. Через терминал можно просматривать счета, открывать и удалять их, менять балансы и выполнять переводы.

## Игровые аккаунты

Игроки могут зарегистрироваться, после чего получают стартовый бонус 100 ЛК. Для регистрации и сохранения изменений введи токен в поле «Токен»; он сохраняется в cookie браузера. Каждый игрок видит свой счет и может пополнять его, списывать средства и переводить их другим игрокам.

Для локального запуска:

```bash
python3 -m http.server 8000
```
